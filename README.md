# 🚢 Titanic Survival Prediction

Machine learning project to predict survival of Titanic passengers.

## 🚀 Features
- Data cleaning
- Feature engineering
- XGBoost model
- Streamlit web app

## 📊 Accuracy
~85%

## 🛠 Tech Stack
- Python
- Pandas
- Scikit-learn
- XGBoost
- Streamlit

## ▶ Run Project
pip install -r requirements.txt
streamlit run app/app.py
